# Jay — Personal Portfolio

A responsive personal portfolio for Penderi Jaya Sai (Jay), built with React, Vite, GSAP, and custom CSS. It includes interactive motion, project showcases, social links, and responsive layouts.

## Run locally

```powershell
npm install
npm run dev
```

## Production build

```powershell
npm run build
npm run preview
```

## Deploy to Netlify

Import this repository in Netlify. The included `netlify.toml` sets the build command to `npm run build` and the publish directory to `dist`.

## Personal assets and links

Personal images are in `public/images/`. Update image paths and profile links in `src/App.jsx` as needed. Verify personal, academic, and project details before publishing.
